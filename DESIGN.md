# Design

The diary extends the starter's warm stone surfaces and amber accents for use outdoors. Use a system sans family and reserve amber for the current view and primary action. Use dark text, plain labels and buttons at least 44 px tall. Keep the diary, history and settings visible in a single navigation row.

Keep capture, review and PDF screens focused on one task. Use actual site photos as the imagery. Put connectivity and save messages above the work, and keep the report available while sync is pending. Use the separate fixed A4 template for employer-facing PDFs.
